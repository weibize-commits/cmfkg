# Released data

This directory contains only redistributable label-only and derived artifacts.

- `evaluation`: adjudicated item IDs, source-work or source-cluster identifiers, and labels.
- `predictions`: frozen system and component probabilities without registered passage text.
- `comparators`: frozen comparator outputs and configuration metadata.
- `oof`: source-work-grouped out-of-fold predictions and manifests.
- `grouped_folds` and `splits`: fold assignments and split metadata.
- `results`: final metrics, paired intervals, calibration outputs, and matched analyses.
- `documentation`: annotation and predicate semantics documentation.
- `figure_source_data`: numerical values used in the quantitative figures.

The exact registered passages and raw archival images are excluded because item-level
public redistribution clearance was not recorded. See the repository README.
