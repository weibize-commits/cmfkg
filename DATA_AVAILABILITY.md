# Data availability and access conditions

This repository contains the de-identified and redistributable data supporting the CMFKG revision. The deposited families include the archived NER expert layers and offset-integrity audit, the human-revalidated relation benchmark, the 300-item B-rule validation, OCR audit data, de-identified user-study outputs, frozen model predictions, analysis scripts, environment records, figure and table source data, and SHA-256 manifests.

The archived NER entity export is supplied for audit transparency but is not a release-validated strict-span benchmark. Character offsets must be realigned to one frozen passage version and ambiguous or unmatched cases must receive expert confirmation before strict-span NER metrics are recomputed. The relation, OCR, rule-validation and user-study materials are not affected by this issue.

Copyrighted scans and complete source books are not distributed. Source identifiers, short verification excerpts, derived annotations and audit transcriptions are included only where redistribution is permitted. Access to excluded third-party material remains subject to its original provider and rights conditions. The public package contains no direct participant identifiers.

Repository URL: https://github.com/weibize-commits/cmfkg
