# Revision 12 supplementary submission mirror

This directory mirrors the three supplementary files prepared for journal upload:

1. `CMFKG_Revision_12_Supplementary_Information.pdf`
2. `Supplementary_Data_1_Verification_Tables.xlsx`
3. `Supplementary_Data_2_Machine_Readable_Resources.zip`

The source data and analysis files underlying these submission-facing files remain organised in the top-level `data/`, `metadata/`, `model_outputs/`, `derived_outputs/` and `analysis/` directories.

The Supplementary Information and verification workbook disclose the unresolved NER offset-integrity issue. They do not claim a DOI, accession or completed archival deposit.
